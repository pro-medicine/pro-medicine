# 스키마 변경 기록 (ERD 대비)

기준 ERD: `backend/docs/supplement-recommendation/reference/erd.sql`.
Flyway를 쓰지 않는다. 엔티티에 반영하면 로컬 DB는 `ddl-auto: update`로 바뀐다.
**2026-10-29부터 AI 테이블은 `backend/docs/sql/AI_SETUP.sql` 하나로 맞춘다** (서버 1회 실행 → 이 파일 실행. AI 테이블을 지우고 다시 만든 뒤 기준 데이터만 넣음).
아래 표의 STEP02~18 SQL은 `backend/docs/sql/archive/`로 옮겼다 (기록용, 실행하지 않음). AI 테이블 구조를 바꾸면 엔티티·`schema.sql`·`AI_SETUP.sql` 1)을 같이 고치고 아래 표에 행을 추가한다.
