# 2026-10-26 에이전트 활용 기록

## 친구 삭제 기능 구현 (은서, Claude, 이슈 #44)

- 친구 삭제 API와 친구 상세 화면의 삭제 버튼(확인창 포함) 추가, 삭제 후 목록으로 돌아가 재조회
- 친구 삭제를 soft delete에서 hard delete로 변경 (삭제 후 재팔로우가 막히던 문제 해결)
- 친구 확인 로직을 하나로 합쳐 상세 조회/삭제에서 같이 사용
- 문제 및 해결
  - 삭제가 반대 방향(상대 → 나)의 관계만 지우던 오류 수정
  - 풀 받은 코드의 Hibernate dialect(MySQL8Dialect) 오류로 서버가 안 뜸 → 설정에서 제거
  - 알림 쪽 쿼리의 deletedAt 조건 때문에 서버 기동 실패 → 조건 제거 방향으로 협의 필요
- 테스트: 친구 삭제, 삭제 후 재신청 확인 예정
- 협의 필요
  - 삭제 시 상대 쪽 관계까지 끊을지(양쪽 삭제) 정책
  - 친구 삭제 시 안부지킴이 설정도 같이 정리할지
  - soft delete 대신 hard delete로 가는 방향을 알림 담당(응진)과 공유

## 안부지킴이 수락/설정 화면 구현 (은서, Claude, 이슈 #45)

- 상대가 보낸 안부지킴이 신청을 상대 프로필의 방패 버튼으로 수락 (수락 대기 시 강조 색으로 표시)
- 서로 친구가 아닌 일방 팔로우 관계는 신청 버튼 비활성화
- 지키는 중일 때 미접속 일수 변경 모달 추가 (왼쪽 안부지킴이 취소, 오른쪽 변경)
- 안내 메시지는 5초 뒤 자동으로 사라지도록 처리
- 모달 포커스 훅 수정: 입력창에 바로 포커스가 가도록 개선, 포커스 대상 지정 시 발생하던 오류 수정
- 문제 및 해결: guardian_setting_id 기본값 오류가 다시 발생 → 현재 DB에 AUTO_INCREMENT 적용
- 테스트: 신청 → 수락 → 일수 변경 → 취소 흐름 확인 예정
- 협의 필요
  - 서버에서도 상호 친구일 때만 신청 가능하도록 검증 추가
  - 거절 화면 위치 (현재는 마이페이지의 받은 요청에서 처리)
  - DB를 새로 만들 때마다 PK AUTO_INCREMENT가 사라지니 공용 스키마 파일 수정 공유
