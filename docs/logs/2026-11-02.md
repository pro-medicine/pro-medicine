## 직접 입력 영양제 등록 및 등록·일정 수정 모달 전환 (주연, Claude Code, 이슈 #98)

- 백엔드 (`domain/product`)
  - `MySupplementAddRequest`에 `manualProductName` 추가, 제품 id와 직접 입력 이름 중 하나만 받도록 검사(둘 다 있거나 둘 다 없으면 400, 100자 초과 400)
  - `MySupplementService.addManualSupplement`: 같은 이름을 복용 중이면 409, 이름만 저장(registeredVia=MANUAL) 후 복용 일정 저장
- 프론트 (`src/mypage`)
  - 영양제 등록·복용 일정 수정을 페이지 전환에서 모달로 변경, 닫으면 연 버튼으로 포커스 복원
  - `SupplementAddPage`에 직접 입력 화면 추가, 하단 요약 문구 제거(변수만 지워 화면이 안 뜨던 오류는 사용하는 줄까지 같이 삭제)
- 브랜치: develop(#104~#108) 머지, `MyPage.jsx` 충돌은 모달 쪽으로 정리하고 머지 중 빠진 #106 달력 처방 연결(`createPrescription`·`deletePrescription`) 복구
- 확인: `pnpm build` 통과, develop 대비 변경 파일이 #98 작업 6개뿐인지 확인
