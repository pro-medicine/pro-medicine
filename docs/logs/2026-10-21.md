## 내 정보 조회 API 동작 확인 (주연, Claude Code, 이슈 #1)

- 테스트 유저(예시 데이터) 1건 넣고 앱 재시작 후 호출
  - `GET /api/v1/users/1` → 200, 유저 정보 응답(passwordHash 없음)
  - `GET /api/v1/users/999` → 404, `U001`
  - `GET /api/v1/users/abc` → 500, `E001` (400이어야 함, 공통 `GlobalExceptionHandler`가 모든 예외를 500으로 처리)
- 협의 필요: `GlobalExceptionHandler`의 잘못된 요청/없는 경로 처리 및 에러 로그 추가
