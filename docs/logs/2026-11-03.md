
## 추천 성분 카드 — "현재 섭취량 미반영" 중복 표시 수정 (영준, Claude Code)

- 브랜치 `feat/v1-onboarding-survey` 그대로, 수정 파일은 `frontend/src/recommendation/IngredientCard.jsx` 하나 (V1 결과·V2 결과·V4 대화창 결과가 같은 카드를 씀)
- 원인: 서버 `DoseCalculator`가 doseNote에 "현재 섭취량 미반영"/"현재 섭취량 단위가 기준 단위와 달라 미반영"을 넣고(상한 조정 문구와 ", "로 이어 붙이기도 함), 카드는 doseNote(rec-hint)와 intakeStatus 줄(rec-intake)을 둘 다 보여 줘서 두 번 나옴
- 수정 내용
  - doseNote를 ", "로 나눠 섭취량 문구 두 개와 "추가 섭취 필요 없음"을 빼고 나머지만 rec-hint로 표시. 남는 게 없으면 줄을 그리지 않음
  - 섭취량 안내는 rec-intake 줄에서 한 번만 표시. doseNote에 단위 불일치 문구가 있으면 "현재 섭취량 미반영" 대신 그 문구
  - amount가 0이면 제목 옆에 "하루 0mg 추가" 대신 "추가 섭취 필요 없음" (사용자 추가 요청)
  - amount가 null이고 intakeStatus도 없으면(기준값 미등록 등) rec-intake 줄을 그리지 않음 (사용자 추가 요청)
  - amount가 null일 때 제목 옆 doseNote, "현재 섭취량 OOO 반영" 문구는 그대로
- 백엔드(doseNote 문구 포함), ResultStep, ChatMessage는 수정하지 않음
- 확인
  - `pnpm build` 통과
  - 카드를 Vite SSR로 렌더링해 경우별 문구 확인 (섭취량 모름 / +상한 조정 / 단위 불일치 / +상한 조정 / 섭취량 앎 / +상한 조정 / amount 0 / amount 0 + 상한 조정 / 기준값 미등록) — 모두 기대대로
  - 화면 확인: 사용자가 직접 확인 예정 (백엔드 fake LLM + Vite 실행해 둠)
