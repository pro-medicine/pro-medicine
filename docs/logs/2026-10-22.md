## Boot 4 전환 후 IntelliJ 부팅 실패 수정 (영준, Claude Code)

- 요청: IntelliJ에서 서버가 안 뜸 (`Unable to resolve name [org.hibernate.dialect.MySQL8Dialect]`)
- 원인: Boot 4의 Hibernate 7에서 `MySQL8Dialect`가 삭제됨. 테스트는 H2라 못 잡음
- 변경 파일: `backend/src/main/resources/application.yml.example` (dialect → `org.hibernate.dialect.MySQLDialect`). 각자 로컬 `application.yml`(Git 제외)도 같은 줄을 바꿔야 함
- 검증: 로컬 MySQL로 `bootRun`(Fake LLM) 부팅 성공, 실제 API 호출 없음
- 협의 필요: develop 머지 시 팀원 전체가 로컬 `application.yml`의 dialect 한 줄 수정 필요 → 전체 공유
