## Claude API 키를 backend/.env에서 읽도록 변경 (영준, Claude Code)

- 요청: API 키를 `.env`에 한 번 넣어두고 로컬에서 계속 쓰도록 수정
- 생성·변경 파일: `backend/src/main/java/com/ucamp/app/infra/llm/LlmConfig.java`(키를 Spring Environment에서 읽음), `AnthropicLlmClient.java`·`LlmProperties.java`(주석·오류 문구), `backend/build.gradle`(`evalRun`·`liveTest`에 `backend/.env`의 키 전달), `application-local-llm.yml`·`backend/README.md`·`backend/docs/perf/TODO-live-runs.md`(안내 문구), `LlmConfigApiKeyTest.java`(새 테스트)
- 검증: `./gradlew test` 통과, `evalRun -PpipelineVersion=V4 -Pcases=2`(confirm 없음, 예상 비용만 출력) 정상. 실제 API는 호출하지 않음
- 협의 필요: 없음. 키는 `backend/.env`(Git 제외)에만 넣는다. 저장소 루트 `.env`는 `.gitignore`에 없으니 쓰지 않는다
