## 식약처 건강기능식품 연동 및 영양 게이지 실데이터 계산 (주연, Claude Code, 이슈 #74)

- 코드는 직접 작성하고, Claude Code에는 설계·코드 예시·오류 원인 설명을 받음
- 백엔드 (`domain/product`)
  - 식약처 건강기능식품정보 API(`HtfsInfoService03/getHtfsItem01`) 호출 `MfdsClient`, 응답 DTO `MfdsProduct`
  - import `POST /api/v1/catalog-products/import?fromPage&toPage&numOfRows`: 페이지마다 트랜잭션, 품목번호로 있으면 수정·없으면 추가(`findByMfdsItemNoIn`, `updateFromMfds`)
  - 저장 제외: 원료용, 제품명에 "수출", 괄호 안 나라 이름, 한글 없는 제품명 (판매 국가 칸이 없어 이름으로 추정)
  - 카테고리 키워드 분류, 기준 및 규격에서 성분 요약(최대 2개) 생성, 주된 기능성은 첫 번째 기능만 저장(번호 표기 `(1)`·`①`·`⑴`, 20자 제한)
  - 영양 게이지: 예시 제품은 예시 함량, 식약처 제품은 성분 요약을 읽어 계산(`parseSummary`, 단위 `㎎`·`μg` 통일)
- 프론트 (`mypage.css`): 검색 결과 섭취 방법 2줄 말줄임, 내 영양제 카드 높이 맞춤
- 오류 해결 질문: 빈 생성자 Bean 오류(`@Component` 누락), PKIX 인증서 오류(로컬 `JAVA_TOOL_OPTIONS=-Djavax.net.ssl.trustStoreType=Windows-ROOT`), AUTO_INCREMENT 변경 시 FK 오류, 중복 `return`, 게이지 500(null 확인 누락)
- 확인: import 1~10페이지 성공, 검색에 식약처 제품 표시, 해외용 제외, 게이지 오메가3 530/500mg(106%), 브라우저에서 카드 높이 같음 확인
- 협의 필요: 기존 DB `catalog_products.catalog_product_id` AUTO_INCREMENT 변경 SQL / 각자 `.env`에 `MFDS_API_KEY` 설정 후 import 1회 실행 / 직접 입력 영양제 함량은 테이블 작업 이후 / 게이지 성분 확장·성별·나이 권장량, 영양제 상세 화면은 다음 이슈
