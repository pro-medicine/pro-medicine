## 친구 목록 스트릭 조회 개선 (은서, Claude)

- 친구마다 스트릭을 따로 계산하던 방식을 일괄 조회로 변경 (친구 수와 상관없이 쿼리 2번)
- 코드 리뷰 반영: 기존 스트릭 계산 로직을 그대로 재사용해 상세 화면과 값이 같도록 유지
- 테스트: 친구 목록 스트릭 표시, 상세와 값 일치 확인 예정
- 협의 필요: 복용 담당(채원)에게 복용 서비스/조회 쿼리 추가 내용 공유

## 날짜별 복용 기록 조회 개선 (은서, Claude)

- 과거 날짜 조회 시 지금 꺼진 일정이라도 그날 복용한 기록이 있으면 함께 표시하도록 쿼리 수정
- 일정이 만들어지기 전 날짜는 표시하지 않도록 조건 추가
- 테스트: 영양제 삭제 후 과거 복용 날짜 클릭 확인 예정
- 협의 필요
  - 일정 유효 기간(언제까지 유효했는지) 컬럼이 없어 기록 없는 과거 날짜는 정확히 판단 불가 → 별도 이슈 협의
  - 달력 동그라미 판단도 같은 기준으로 정리할 시점
  - 홈 오늘 목록에 같은 쿼리를 쓰므로 채원과 공유

  - 다른 도메인 테이블은 조회 전용 Repository로만 읽음 (복용 도메인 코드 수정 없음)
