## 친구 목록 스트릭 조회 개선 (은서, Claude)

- 친구마다 스트릭을 따로 계산하던 방식을 일괄 조회로 변경 (친구 수와 상관없이 쿼리 2번)
- 코드 리뷰 반영: 기존 스트릭 계산 로직을 그대로 재사용해 상세 화면과 값이 같도록 유지
- 테스트: 친구 목록 스트릭 표시, 상세와 값 일치 확인 예정
- 협의 필요: 복용 담당(채원)에게 복용 서비스/조회 쿼리 추가 내용 공유

## 날짜별 복용 기록 조회 개선 (은서, Claude)

- 과거 날짜 조회 시 지금 꺼진 일정이라도 그날 복용한 기록이 있으면 함께 표시하도록 쿼리 수정
- 일정이 만들어지기 전 날짜는 표시하지 않도록 조건 추가
- 테스트: 영양제 삭제 후 과거 복용 날짜 클릭 확인 예정
- 협의 필요
  - 일정 유효 기간(언제까지 유효했는지) 컬럼이 없어 기록 없는 과거 날짜는 정확히 판단 불가 → 별도 이슈 협의
  - 달력 동그라미 판단도 같은 기준으로 정리할 시점
  - 홈 오늘 목록에 같은 쿼리를 쓰므로 채원과 공유

## 복용 달력 일정 기능 구현 (은서, Claude)

- 날짜를 누르면 모달로 복용 기록과 일정을 확인하도록 변경 (기존 하단 표시 영역 제거)
- 모달에서 일정(주사, 처방약, 일회성 복용, 병원 방문, 기타) 추가/수정/삭제
- 일정이 있는 날짜 우측 상단에 작은 점 표시, 다음 달과 미래 날짜도 선택 가능
- 일정 완료 체크 추가 (완료 상태 변경 API 추가, 모두 완료한 날은 점 색을 흐리게 표시)
- 일정은 민감 정보라 내 달력에서만 사용하고, 친구 달력에는 표시하지 않음
- 문제 및 해결
  - 완료 버튼이 보이지 않음 → 내 달력에 상태 변경 연결이 빠져 있던 것 수정
  - 친구 달력에 일정 추가/삭제가 연결되어 내 일정 API를 호출하던 것 제거
- 테스트: 일정 추가/수정/삭제/완료, 점 표시, 월 이동, 친구 달력에서 일정 미노출 확인 예정
- 협의 필요
  - 일정 기간(종료일) 지원 여부와 기간 내 날짜별 점 표시
  - 약 복용 기간 중 영양제 주의 알림 연동 시점 (일정 종류와 정보 테이블 연결 후)
  - calendar_event 테이블 PK AUTO_INCREMENT 및 생성일 자동 입력 설정 확인
  - 일정 API의 PUT, PATCH, DELETE 허용(CORS) 확인
